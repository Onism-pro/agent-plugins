# 部署

假定 AstrBot 用 Docker 跑，容器名 `astrbot`，宿主机数据目录 `/opt/astrbot/data`（容器内是 `/AstrBot/data`）。路径不同就按自己的改。

## 0. 先备份

```bash
cp /opt/astrbot/data/data_v4.db /opt/astrbot/data/data_v4.db.bak_$(date +%Y%m%d)
```

压缩和遗忘都会写这个库，出问题就停容器、把备份拷回去。

## 1. 装原文日志插件

```bash
cp -r plugins/memory_rawlog /opt/astrbot/data/plugins/
docker restart astrbot
docker logs astrbot --since 2m | grep memory_rawlog
```

看到 `memory_rawlog 已就绪` 就成了。发一条消息，确认 `data/plugin_data/memory_rawlog/hot/` 里出现了当天的 jsonl。

> 如果一条都没记：检查插件里的事件类型。`filter.EventMessageType.ALL` 是个位掩码，值为 0，等于匹配不到任何消息——必须写成 `PRIVATE_MESSAGE | GROUP_MESSAGE`。

## 2. 找到会话 UMO

UMO 就是 `平台:FriendMessage:xxxx@im.wechat` 这种字符串，在 `data_v4.db` 里能查：

```bash
sqlite3 /opt/astrbot/data/data_v4.db \
  "SELECT DISTINCT user_id FROM conversations;"
```

或者看日志里 `[default] [平台(适配器)]` 那一行。

## 3. 试运行压缩

```bash
export MEMORY_KIT_API_KEY=sk-xxx
export MEMORY_KIT_API_BASE=https://api.deepseek.com/v1
export MEMORY_KIT_MODEL=deepseek-chat

python3 scripts/compact_history.py \
  --db /opt/astrbot/data/data_v4.db \
  --umo "你的UMO" \
  --note-dir /opt/astrbot/data/plugin_data/astrbot_plugin_angel_memory/raw/.angel/note \
  --trigger 90 --keep 50
```

这一步只打印摘要、不动数据库。**看清楚摘要有没有丢关键信息**，再决定下一步。

## 4. 正式启用

```bash
docker stop astrbot
python3 scripts/compact_history.py ... --apply
docker start astrbot
```

或者直接用封装好的脚本，它会自己判断条数、停容器、压缩、起容器：

```bash
UMO="你的UMO" \
DB=/opt/astrbot/data/data_v4.db \
NOTE_DIR=/opt/astrbot/data/plugin_data/astrbot_plugin_angel_memory/raw/.angel/note \
CONTAINER=astrbot \
/opt/memory-kit/scripts/compact_run.sh
```

挂到 crontab（排在备份之后）：

```cron
40 4 * * *  /bin/bash /opt/memory-kit/scripts/compact_run.sh
```

## 5. 审计

```bash
# 每周一：这几天说过的话里，哪些事实没进库
50 4 * * 1  python3 /opt/memory-kit/scripts/audit_evidence.py \
  --hot /opt/astrbot/data/plugin_data/memory_rawlog/hot \
  --db /opt/astrbot/data/plugin_data/astrbot_plugin_angel_memory/memory_center/index/simple_memory.db \
  --days 7 --out-dir /opt/astrbot/data/plugin_data/memory_rawlog

# 每周日：哪些记忆该淡出了（先不加 --apply，裸跑看几周）
45 4 * * 0  python3 /opt/memory-kit/scripts/audit_forget.py \
  --db /opt/astrbot/data/plugin_data/astrbot_plugin_angel_memory/memory_center/index/simple_memory.db
```

## 6. 回滚

- 压缩：`docker stop astrbot` → 把备份的 `data_v4.db` 拷回去 → 起容器。摘要笔记可以留着，不影响。
- 遗忘：`audit_forget.py` 每次动作前都会生成 `simple_memory.db.bak_时间戳`；也可以从 `memory_archive` 手动搬回 `memory_records`。
- 插件：删掉 `data/plugins/memory_rawlog/` 目录，重启即可。
